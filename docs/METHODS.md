# Methods and limitations

Version 0.99.2 is a development version. The table describes the implemented procedures. The primary sources provide background; package-specific adaptations and exploratory diagnostics require separate validation. Numerical results are reported in [the validation report](VALIDATION_REPORT.md).

| Function | Implemented method and limits | Sources |
|---|---|---|
| `sci_describe` | Per-group descriptive statistics and biological-unit averaging. The median interval uses approximate order-statistic bounds; it is not an exact finite-sample interval. | [vaux2012](REFERENCES.md#vaux2012), [hett2010](REFERENCES.md#hett2010) |
| `sci_normality` | Shapiro-Wilk and optional Anderson-Darling diagnostics, with skewness and kurtosis summaries. A non-rejection does not establish normality. | [royston1992](REFERENCES.md#royston1992), [stephens1974](REFERENCES.md#stephens1974), [doane2011](REFERENCES.md#doane2011), [rochon2012](REFERENCES.md#rochon2012) |
| `sci_outliers` | Exploratory IQR, MAD, and z-score flags. The function returns flags rather than removing observations. | [tukey1977](REFERENCES.md#tukey1977), [hampel1974](REFERENCES.md#hampel1974), [iglewicz1993](REFERENCES.md#iglewicz1993) |
| `sci_compare` | Two-group t, rank, and permutation comparisons. Test choice and exchangeability assumptions depend on the experimental design. | [welch1947](REFERENCES.md#welch1947), [rochon2012](REFERENCES.md#rochon2012), [davison1997](REFERENCES.md#davison1997) |
| `sci_anova` | Classical ANOVA or a one-way Welch alternative, with effect-size summaries. The variance diagnostic uses Welch ANOVA on median-centred absolute deviations; it is not a call to car::leveneTest. | [welch1951](REFERENCES.md#welch1951), [kelley1935](REFERENCES.md#kelley1935), [carroll1975](REFERENCES.md#carroll1975), [hsu1996](REFERENCES.md#hsu1996) |
| `sci_regression` | Linear, weighted, robust, or nonlinear regression. The requested model and its error assumptions determine the interpretation of intervals. | [huber1981](REFERENCES.md#huber1981), [bates1988](REFERENCES.md#bates1988), [drapersmith1998](REFERENCES.md#drapersmith1998) |
| `sci_correlation` | Pearson, Spearman, or Kendall association. The Fisher-transform interval uses an approximate critical value and does not establish causation. | [fisher1915](REFERENCES.md#fisher1915), [fisher1921](REFERENCES.md#fisher1921), [bonett2000](REFERENCES.md#bonett2000) |
| `sci_bootstrap` | Observation, cluster, or stratified resampling with percentile, normal, or BCa intervals. Resampling must preserve the design's dependence structure. | [efron1979](REFERENCES.md#efron1979), [efron1987](REFERENCES.md#efron1987), [efron1993](REFERENCES.md#efron1993), [davison1997](REFERENCES.md#davison1997) |
| `sci_power` | Analytic or simulated power under a specified effect and sampling model. Calculations do not account automatically for model misspecification. | [cohen1988](REFERENCES.md#cohen1988), [fisher1921](REFERENCES.md#fisher1921), [bonett2000](REFERENCES.md#bonett2000) |
| `sci_effect_size` | Standardised effect-size estimates and approximate intervals. Paired and independent designs use different standardisers. | [cohen1988](REFERENCES.md#cohen1988), [hedges1985](REFERENCES.md#hedges1985), [morris2002](REFERENCES.md#morris2002) |
| `adaptive_baseline` | Asymmetric least-squares or lowess baseline estimation. The estimated baseline can absorb genuine broad signal features. | [eilers2005](REFERENCES.md#eilers2005), [eilers2003](REFERENCES.md#eilers2003), [cleveland1979](REFERENCES.md#cleveland1979) |
| `adaptive_smoothing` | Local polynomial Savitzky-Golay, spline, or lowess smoothing. Window selection is a package-specific heuristic; smoothing changes the dependence between observations. | [savitzky1964](REFERENCES.md#savitzky1964), [steinier1972](REFERENCES.md#steinier1972), [cleveland1979](REFERENCES.md#cleveland1979) |
| `weighted_peak_fit` | Nonlinear least-squares peak fitting. The pseudo-Voigt-style option fits a Gaussian/Lorentzian mixture with a shared width parameter; it does not implement the Thompson width-dependent approximation. | [bates1988](REFERENCES.md#bates1988), [thompson1987](REFERENCES.md#thompson1987) |
| `replicate_decompose` | Mixed-model or simple variance-component decomposition. Boundary estimates and uncertainty in small designs require care. | [bates2015](REFERENCES.md#bates2015), [searle1992](REFERENCES.md#searle1992), [pinheiro2000](REFERENCES.md#pinheiro2000) |
| `drift_correct_stat` | A fitted drift curve is subtracted with an uncertainty estimate. Without reference standards, the running-median fallback can confound drift and genuine change. | [bates1988](REFERENCES.md#bates1988), [oehlert1992](REFERENCES.md#oehlert1992) |
| `robust_lod` | Currie-style, blank-SD, and Hubaux-Vos-style detection calculations. These are implementation-specific approximations, not complete reproductions of every procedure in the cited papers. | [currie1968](REFERENCES.md#currie1968), [hubaux1970](REFERENCES.md#hubaux1970), [currie1995](REFERENCES.md#currie1995) |
| `calibration_compare` | Linear-model comparisons of calibration slopes and intercepts. Interpretation depends on the adequacy and comparability of the calibration designs. | [drapersmith1998](REFERENCES.md#drapersmith1998) |
| `curve_similarity` | Curve distances, dynamic time warping, or correlation, with optional bootstrap intervals. A distance below a threshold is a diagnostic criterion rather than an established equivalence test. | [sakoe1978](REFERENCES.md#sakoe1978), [fisher1921](REFERENCES.md#fisher1921), [efron1993](REFERENCES.md#efron1993), [wellek2010](REFERENCES.md#wellek2010) |
| `kinetic_model_compare` | Candidate kinetic models are fitted and compared using AIC/BIC and sensitivity diagnostics. Convergence and identifiability affect the comparison. | [seber1989](REFERENCES.md#seber1989), [akaike1974](REFERENCES.md#akaike1974), [bates1988](REFERENCES.md#bates1988) |
| `spectral_change_test` | Hotelling-type, distance-based permutation, or pointwise comparisons. Dispersion differences and dependence can affect interpretation. | [anderson2001](REFERENCES.md#anderson2001), [anderson2006](REFERENCES.md#anderson2006), [hotelling1931](REFERENCES.md#hotelling1931), [bh1995](REFERENCES.md#bh1995), [warton2012](REFERENCES.md#warton2012) |
| `noise_characterize` | Trend removal or successive differences, autocorrelation, and a raw FFT periodogram. Its heteroscedasticity diagnostic correlates absolute residuals with fitted values; it is neither White's test nor the studentized Breusch-Pagan test. The FFT output is not Welch's averaged periodogram. | [box2008](REFERENCES.md#box2008) |
| `parameter_uncertainty` | Delta-method, multivariate-normal Monte Carlo, or bootstrap propagation under the supplied fitted model. | [oehlert1992](REFERENCES.md#oehlert1992), [efron1993](REFERENCES.md#efron1993) |
| `timepoint_optimize` | Greedy candidate-time selection using information or model-separation criteria. The search does not guarantee a global optimum or implement a non-normal KL-discrimination criterion. | [fedorov1972](REFERENCES.md#fedorov1972), [atkinson2007](REFERENCES.md#atkinson2007) |
| `batch_effect_quantify` | Random-intercept variance decomposition or fixed-effect batch comparisons for a univariate response. | [bates2015](REFERENCES.md#bates2015), [searle1992](REFERENCES.md#searle1992), [pinheiro2000](REFERENCES.md#pinheiro2000) |
| `signal_difference_regions` | A maximum-statistic permutation threshold or Bonferroni fallback is used to mark grid regions. The code uses a single-step maximum statistic, not the full Westfall-Young step-down algorithm. Calibration requires exchangeability and a suitable design. | [westfall1993](REFERENCES.md#westfall1993) |
| `peak_evidence` | Baseline-subtracted amplitude, a Gaussian likelihood-style score, and a resampling tail fraction. The observed and resampled contrasts differ, and the candidate set is not re-detected. Neither exact false-positive calibration nor a location confidence interval is established. | [wilks1938](REFERENCES.md#wilks1938), [currie1968](REFERENCES.md#currie1968) |
| `calibration_transfer_risk` | Univariate offset or affine transfer corrections with parameter resampling. Multivariate transfer papers supply context, not validation of this univariate interval construction. Local interval coverage was below nominal. | [wang1991](REFERENCES.md#wang1991), [bouveresse1996](REFERENCES.md#bouveresse1996), [feudale2002](REFERENCES.md#feudale2002) |
| `kinetic_discrimination` | Monte Carlo estimates of selection frequencies for candidate kinetic models under a chosen data-generating model. These frequencies depend on the supplied parameters and noise model. | [asprey2000](REFERENCES.md#asprey2000) |
| `experiment_fragility` | Exploratory sensitivity to analysis decisions and perturbations. It is related to clinical fragility and multiverse analysis, but is not the clinical binary-event fragility index. | [walsh2014](REFERENCES.md#walsh2014), [steegen2016](REFERENCES.md#steegen2016) |
| `drift_uncertainty` | Variance fractions under a fitted drift model with bootstrap diagnostics. Local nominal 95% intervals covered only 43% in the tested linear scenario. | [seber1989](REFERENCES.md#seber1989), [davison1997](REFERENCES.md#davison1997) |
| `detection_reliability` | Concentration-dependent detection probabilities under the fitted Gaussian calibration model. Analytical detection sources supply the decision-limit framework, not general validation of this bootstrap implementation. | [currie1999](REFERENCES.md#currie1999), [currie1995](REFERENCES.md#currie1995), [hubaux1970](REFERENCES.md#hubaux1970) |
| `uncertainty_origin` | Covariance sharing for the game v(S) = Var(sum of stages in S). Each covariance is split equally between its two stages. This differs from conditional-expectation Shapley effects in the related literature. Simulation sums multivariate-normal additive errors; total_ci is an interval for simulated errors, not a confidence interval for variance. | [owen2017](REFERENCES.md#owen2017), [song2016](REFERENCES.md#song2016), [draper1995](REFERENCES.md#draper1995), [gum2008](REFERENCES.md#gum2008) |
